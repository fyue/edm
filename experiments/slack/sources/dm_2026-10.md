> また、Restart の時刻と EDM の時刻の定義が違うと思いますが...
EDMでは、σはそのまま時刻t(つまりσ(t)=t)を採用しています。Restartの公式実装を確認したところ、sigma_min、sigma_maxからスケジューラt_stepsを計算し、d_curを計算する処理はEDMとは同じであることを確認しました。これまで実行してきたいくつかのRestartの実験も以下のRestart公式実装のコードを流用していますので、時刻の定義は同じだと認識しています。
```    t_steps = (sigma_max ** (1 / rho) + step_indices / (num_steps - 1) * (
                sigma_min ** (1 / rho) - sigma_max ** (1 / rho))) ** rho
    t_steps = torch.cat([net.round_sigma(t_steps), torch.zeros_like(t_steps[:1])])```
```    gamma = min(S_churn / num_steps, np.sqrt(2) - 1) if S_min <= t_cur <= S_max else 0
    t_hat = net.round_sigma(t_cur + gamma * t_cur)
    x_hat = x_cur + (t_hat ** 2 - t_cur ** 2).sqrt() * S_noise * randn_like(x_cur)
    # Euler step.

    denoised = net(x_hat, t_hat, class_labels).to(torch.float64)
    d_cur = (x_hat - denoised) / t_hat
    x_next = x_hat + (t_next - t_hat) * d_cur```
