# 概要と合意事項

## 研究の主題

「十分に学習できていないモデルに対して、Restartによるサンプリングで品質を改善できるか」と、「使える学習データ自体が少ない場合にも改善できるか」を分けて検証する。先生は、両者を同じ問題として扱わないよう指示している。[9月26日DM](https://kato-ai-lab.slack.com/archives/D08LCS5CPM3/p1790392377153739)

出発点は固定K=5の比較だったが、checkpointごとにK=0〜8を走査し、学習量と最適Kの関係を見る方針になった。修論用には10kまたは20k刻みの均等なcheckpointを残す。[9月18日DM](https://kato-ai-lab.slack.com/archives/D08LCS5CPM3/p1789657400863009)

## 最新の方針

1. **主実験はN_main=18固定。** N_restart=3、t_min=0.14、t_max=0.30、K=0〜8。NFEは35+4Kで増える。Restart回数の影響を見る実験として位置づける。[10月7日DM](https://kato-ai-lab.slack.com/archives/D08LCS5CPM3/p1791362856017499)
2. **補完実験はNFE=55固定。** N_main=28−2Kであり、主スケジュールとactual_t_minも変わる。「計算量固定＋Restart実装での挙動」を見る実験とし、Kだけの効果とは区別する。実際のt_minの表も論文に掲載する。[10月13日DM](https://kato-ai-lab.slack.com/archives/D08LCS5CPM3/p1791896608521359)
3. **論文の図はFID-50kを使う。** 重要点では3生成seed範囲で平均と標準偏差を確認する。これは3回の独立学習ではない。[10月15日DM](https://kato-ai-lab.slack.com/archives/D08LCS5CPM3/p1792073222757459)、[10月19日スレッド](https://kato-ai-lab.slack.com/archives/C082JD35X5W/p1792419349323939)
4. **Kの傾向図には、まず単純平均を採用する。** 11月2日に提案された2案のうち、先生は計算根拠が素直な平均値の案を優先した。指数重み付き平均`exp(−FID差/0.02)`は提案されたが、主採用の合意はない。[11月2日最終返信](https://kato-ai-lab.slack.com/archives/C082JD35X5W/p1793628822297069)
5. **データ不足は30,000枚の1ケースから。** 全サイズの実施は必須ではなく、FIDの改善が望めなくなれば200kより前に打ち切ってよい。[10月2日DM](https://kato-ai-lab.slack.com/archives/D08LCS5CPM3/p1790950994360789)

単純平均の具体的な対象を「最良FIDとの差が0.02以下のK」とするのは、現行プロットコードで確認した仕様。先生自身が0.02という閾値を指定したわけではない。平均は最適Kの代替推定値や統計的同等性の判定ではなく、近い性能を持つK群の中心を示す記述量とする。

## t_minについての指示の変遷

10月5日に、EDM向け推奨区間(0.14, 0.30)と、それまでの(0.06, 0.30)の違い、時刻の対応を確認するよう指示された。初期checkpointでは0.06が有利との報告を受け、10月6日には一度0.06を使う方向になった。その後170kでは0.14が良いという結果を踏まえ、**10月7日に0.14を主実験の基準とする方針へ更新された**。古いDMだけを根拠に0.06を主設定に戻さない。[10月5日](https://kato-ai-lab.slack.com/archives/D08LCS5CPM3/p1791193680732089)、[10月6日](https://kato-ai-lab.slack.com/archives/D08LCS5CPM3/p1791293841705399)、[10月7日](https://kato-ai-lab.slack.com/archives/D08LCS5CPM3/p1791362856017499)

0.06との比較は、修論の発展的実験またはAppendixで、パラメータの選定理由を説明する資料として残す。

## 報告された結果

- **50,000枚学習：** N_main固定・NFE固定の双方で、baseline FIDが悪いモデルほどRestartの改善幅が大きい傾向がある、と先生が評価した。baseline FIDを横軸、K=0比の改善幅を縦軸にした図が必要。[10月22日](https://kato-ai-lab.slack.com/archives/C082JD35X5W/p1792676167958939)
- **3シード確認：** 20k/60k/100k/140k/180k/200kのN_main固定評価が報告済み。平均改善幅は順に0.38073/0.10470/0.04310/0.03058/0.01933/0.01344。180k・200kでは改善が小さく、ばらつきも併記する必要がある。[10月27日](https://kato-ai-lab.slack.com/archives/C082JD35X5W/p1793027847627969)
- **200k以降：** 1生成seed範囲ではK=0のFIDが200k=1.80678、210k=1.83710、220k=2.00929。220kではK=1が2.05315となり悪化した。200k・210kの3範囲平均でもK=1による小さな改善が報告された。220kのK=0/K=1の観測を、すべてのKやすべてのモデルへの結論には広げない。[10月22日](https://kato-ai-lab.slack.com/archives/C082JD35X5W/p1792674670089809)、[10月27日](https://kato-ai-lab.slack.com/archives/C082JD35X5W/p1793028436537769)
- **30,000枚学習：** CIFAR-10の50,000枚からsubset seed=0で30,000枚を抽出し100kまで学習した結果が報告済み。約50k以降のFID悪化を過学習的な挙動と解釈している。[11月1日、指定メッセージ](https://kato-ai-lab.slack.com/archives/C082JD35X5W/p1793500915020579)
- **先生の最新の解釈：** 30,000枚でも学習不足段階ではRestartで改善し、十分学習すると逆に悪化する傾向が見える。40kはイレギュラー。先生は、学習データ不足自体はRestartで救えない、という解釈を示した。これは今回の条件に対する見解として記載し、全データ不足状況への一般的証明とは扱わない。[11月2日](https://kato-ai-lab.slack.com/archives/C082JD35X5W/p1793628822297069)
