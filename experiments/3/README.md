# 実験3：160k以降のlearning rate・EMA探索

## 問い

基準学習（[1-cifar10-...](../1-cifar10-cond-ddpmpp-edm-seed0-200k-fid2.18/README.md)）では120k以降にFIDが悪化した。120k・160kのcheckpointを起点にlearning rateとEMA half-lifeを変え、どの条件まで継続すればFIDが最良になるかを調べる。

## 主要な結論

- **最良は3-10の`170000` snapshot、FID-50kの3 seed平均は1.85124**。`lr=0.001, EMA=0.5`で到達した160k（FID約2.05）から、`lr=0.0002, EMA=0.5`に下げて170kまで継続したもの。8-7・8-8では「実験3のbest」としてこのsnapshotを使っている。出典：[report/2026-06-27_...md](report/2026-06-27_additional_report_lr_ema_160k_after_mean_fid.md)。
- 160k以降に小さいlr（2e-4、1.5e-4、1e-4）で継続すると、170k前後まではFIDが改善し、その後は悪化する（3-12、3-13、3-17）。lrを上げる方向（1.5e-3、3-14）は2.30〜2.54と大きく悪化する。
- 3-18（lr=1e-4）の175k（約1.89）から継続した場合、最良値は3-19（lr=1e-4）で185035の1.91013、3-20（lr=5e-5）で185035の1.90343。いずれも1.85124には届かない。出典：各`results/aggregate.tsv`。
- 学習率を下げるだけでは足りず、起点にするcheckpointの選び方も結果に影響する。
