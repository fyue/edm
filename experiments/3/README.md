# 実験3：160k以降のlearning rate・EMA探索

## 問い

基準学習（[1-cifar10-...](../1-cifar10-cond-ddpmpp-edm-seed0-200k-fid2.18/README.md)）では120k以降にFIDが悪化した。120k・160kのcheckpointを起点にlearning rateとEMA half-lifeを変え、どの条件まで継続すればFIDが最良になるかを調べる。

## 主要な結論

数値はFID-50k（18 steps、3 seed範囲の平均）。

- **最良は3-10の`170000` snapshot、1.85124**。3-1の元設定（`lr=0.001, EMA=0.5`）で到達した160k（2.050）から、`lr=0.0002`に下げて170kまで継続したもの。8-7・8-8では「実験3のbest」としてこのsnapshotを使っている。出典：[3-10 aggregate.tsv](10_160k-fid2.05-to-170k-lr2e-4-ema0.5/results/aggregate.tsv)、[report/2026-06-27_...md](report/2026-06-27_additional_report_lr_ema_160k_after_mean_fid.md)。
- **同じ160k起点なら、lrを2e-4・1.5e-4・1e-4のどれにしても170kはほぼ同じ**（3-10が1.851、3-16が1.854、3-18が1.858。seed間のstdは0.02〜0.03）。3-10が最良なのは1点の比較で、lrの差は誤差の範囲内。
- **170kより先へ継続すると悪化する**。3-10の170kから続けた3-12・3-13は2.03〜2.14、3-16の170kから続けた3-17は2.01。3-18の175k（1.890）から続けた3-19・3-20は、最良が185kの1.910／1.903で、190kでは2.03／2.01。
- **起点の選び方も結果に影響する**。120k→160kでは`lr=5e-4`の枝が最良だった（2.010。元設定2.050、EMA=1.0は2.162。[3-1](1_120k-160k-lr-ema-sweep/results/summary.tsv)）。しかし同じ`lr=2e-4`で170kまで続けると、その枝からの3-3は1.939にとどまり、元設定の枝からの3-10（1.851）に及ばなかった。
- `lr=5e-4`のまま続けると、170k付近は2.01〜2.04で横ばい、200kは2.292（3-2、3-4、3-11）。3-3の170kから続けると、lr（2e-4、1e-4、5e-5）によらず175k〜180kで2.23〜2.66に悪化した（3-5〜3-7、3-9）。
- lrを上げる方向（1.5e-3）は2.31〜2.54と大きく悪化する（3-14）。
- 3-6・3-7で3-3の170kを再評価すると、3-3と完全に同じFIDになった（同じsnapshot・seedでFIDは決定論的に再現する）。
